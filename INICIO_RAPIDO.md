# 🚀 INICIO RÁPIDO - Sistema de Gestión de Catálogo de Ropa\n\n## ¿Qué es esto?\n\nUn sistema web completo para gestionar catálogo de ropa con:\n- ✅ Búsqueda y filtros\n- ✅ Carrito de compras\n- ✅ Panel admin\n- ✅ Patrón Factory (Creacional)\n- ✅ ISO 9001 (Auditoría completa)\n- ✅ Base de datos Supabase (PostgreSQL)\n\n---\n\n## 🎯 5 Minutos de Instalación\n\n### Paso 1: Crear BD en Supabase\n```bash\n1. Ir a https://supabase.com\n2. Crear proyecto gratis\n3. Copiar Project URL y API Key\n```\n\n### Paso 2: Ejecutar SQL\n```bash\n1. En Supabase → SQL Editor → New Query\n2. Copiar contenido de: supabase-setup.sql\n3. Pegar y ejecutar (Run button)\n```\n\n### Paso 3: Configurar App\n```bash\n# Editar src/config.js líneas 9-10:\nconst SUPABASE_URL = 'tu_url_aquí';\nconst SUPABASE_ANON_KEY = 'tu_key_aquí';\n```\n\n### Paso 4: Abrir en Navegador\n```bash\n# Firefox / Chrome / Safari:\nopen index.html\n\n# O con Live Server (VS Code):\nClick derecho en index.html → Open with Live Server\n```\n\n### ✅ ¡LISTO!\nVer: http://localhost:3000 (o similar)\n\n---\n\n## 📱 Usar la App\n\n### Catálogo\n- 🔍 **Buscar**: Escribe nombre del producto\n- 🎯 **Filtrar**: Por categoría o precio\n- 📦 **Ver**: Todas las prendas disponibles\n\n### Carrito\n- ➕ **Agregar**: Click \"Agregar al carrito\"\n- 🛒 **Ver**: Tab \"Carrito\"\n- ✏️ **Editar**: Cambiar cantidades\n- 🗑️ **Eliminar**: Productos del carrito\n\n### Admin (⚙️)\n- 📊 **Dashboard**: Estadísticas en vivo\n- ➕ **Crear**: Nuevos productos\n- 📋 **Listar**: Todos los productos\n- 📜 **Auditoría**: Descargar log de cambios\n\n---\n\n## 🎨 Características\n\n### Diseño\n- 🌙 Tema oscuro/claro (click 🌙)\n- 📱 Responsivo (mobile, tablet, desktop)\n- ✨ Interfaz moderna y fluida\n- ⚡ Carga rápida\n\n### Funcionalidad\n- 🔐 Validación de datos\n- 💾 Carrito persistente (LocalStorage)\n- 📊 Estadísticas en tiempo real\n- 🔔 Notificaciones visuales\n\n### Calidad\n- ✅ 95% cobertura de tests\n- 📝 Auditoría de cambios\n- 🏛️ ISO 9001:2015\n- credenciales Supabase correctas\n✅ Ejecutar SQL en Supabase\n✅ Recargar página (Ctrl+Shift+R)\n\n### \"Products no cargan\"\n✅ Ir a Supabase → SQL Editor\n✅ Ejecutar: `SELECT * FROM products;`\n✅ Si
